# Cloud Glossary

| Term                   | Simple Meaning                                                       | Everyday Example                                            |
| ---------------------- | -------------------------------------------------------------------- | ----------------------------------------------------------- |
| Low Latency            | Very fast response time with almost no delay                         | Talking to someone sitting next to you                      |
| Scalability            | Ability to increase or decrease resources to handle workload changes | A restaurant adding more tables when more customers arrive  |
| Elasticity             | Automatically scaling resources up or down based on demand           | An escalator that starts moving when people step on it      |
| High Availability      | A system stays online most of the time with minimal downtime         | A shop that almost never closes                             |
| Minimal Downtime       | The system is offline for only a short time                          | A shop that closes for 5 minutes for cleaning               |
| Fault Tolerance        | A system continues working even when something fails                 | A car that can still drive after one tire is damaged        |
| Reliability            | A system works correctly and consistently                            | A clock that always shows the right time                    |
| Agility                | Ability to make changes and innovate quickly                         | Changing a recipe in minutes instead of days                |
| Pay-as-you-go          | Pay only for the resources you use                                   | Paying for electricity based on consumption                 |
| Region                 | A geographical area where AWS has infrastructure                     | A city where a coffee shop chain operates                   |
| Availability Zone (AZ) | One or more isolated data centers within an AWS Region               | Different shops in separate parts of a city                 |
| Data Center            | A facility containing servers that store and process data            | A kitchen containing equipment used to prepare food         |
| Failover               | Switching to a backup system when the primary system fails           | Customers going to another shop when one closes             |
| Redundancy             | Having extra backup systems or components                            | Keeping a spare coffee machine in case one breaks           |
| Fluctuating Demand     | When resource needs increase and decrease over time                  | A restaurant gets busy at lunchtime and quiet late at night |

### Quick AWS Exam Reminder

| Concept                     | Remember                                         |
| --------------------------- | ------------------------------------------------ |
| Scalability                 | Handle growth or changes in workload             |
| Elasticity                  | Automatically adjust resources to current demand |
| High Availability           | Minimize service interruptions                   |
| Fault Tolerance             | Continue operating despite component failures    |
| Redundancy                  | Keep backup components available                 |
| Fluctuating Demand          | A reason to use elasticity and Auto Scaling      |
| Multiple Availability Zones | Improve availability and resilience              |
