## Cloud Glossary
Here’s the clean table:

| Term                | Simple Meaning                                      | Everyday Example |
|---------------------|-----------------------------------------------------|------------------|
| **Low Latency**     | Very fast response time (almost no delay)           | Talking to someone sitting next to you |
| **Scalability**     | Ability to easily increase or decrease resources    | A restaurant that can quickly add more tables when more customers come |
| **Elasticity**      | Automatically scales up or down based on demand     | An escalator that starts moving only when people step on it |
| **High Availability** | System stays online most of the time              | A shop that almost never closes |
| **Fault Tolerance** | System continues working even if something fails    | A car that can still drive if one tire gets damaged |
| **Reliability**     | System works correctly and consistently             | A clock that always shows the right time |
| **Agility**         | Ability to quickly make changes and innovate        | Changing a recipe in minutes instead of days |
| **Pay-as-you-go**   | Pay only for what you actually use                  | Paying for electricity only for the hours you use it |
