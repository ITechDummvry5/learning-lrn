Git Command Reference

From first commit to sparse checkout

GitGitHubVersion Control
Getting Started
1 Setup & Configuration
CommandDescription
git initInitialize a brand new Git repository in the current folder
git config --global user.name "Name"Set your name for all commits across all projects
git config --global user.email "email"Set your email for all commits
git config --listShow all current Git configuration settings
2 Clone & Create
CommandDescription
mkdir github-projectsCreate a folder on your computer where projects will live
git clone <url>Copy a GitHub repository URL and download it to your computer
cd repo-nameNavigate into the cloned repository folder
touch filename.htmlCreate a new file inside the repo folder
3 Stage & Commit
CommandDescription
git add filenameStage a specific file so Git starts tracking it
git add .Stage all new and modified files at once
git add -AStage everything — new files, modifications, and deletions
git add -uStage only modified and deleted tracked files; ignores new files
git add -pInteractive — choose exactly which changes within files to stage
git commit -m "msg"Commit staged changes with a message
git commit -am "msg"Stage all tracked files AND commit in one command (skips new untracked files)
git commit --amendModify the last commit — change the message or add more files
git commit --amend --no-editAdd staged changes to the last commit without changing its message
git commit --allow-empty -m "msg"Create a commit with no file changes — useful for triggering CI
git commit -m "msg" --no-verifySkip pre-commit hooks and checks
4 Push & Pull
CommandDescription
git push origin mainPush your local commits to your remote GitHub repository
git push -u origin branchPush a branch and set it to track the remote, simplifying future pushes
git push --allPush all local branches to GitHub at once
git push --forceForce push even if it overwrites remote changes — use with caution
git pullDownload and merge the latest changes from GitHub into your local branch
git pull origin branchDownload and merge changes from a specific remote branch
git fetchDownload remote changes without merging — review before pulling
Inspecting Changes
5 Status & Diff
CommandDescription
git statusShow modified, staged, and untracked files — run before committing
git status -sCompact short-form status output
git status --porcelainMachine-readable status output, useful for scripts
git diffShow line-by-line changes between working files and the last commit
git diff --stagedShow changes that are staged and ready to be committed
git diff HEADShow all changes, staged and unstaged, since the last commit
git diff branch1 branch2Compare differences between two branches
git show <hash>Show full details of a specific commit including all changes
git fsckCheck repository integrity — useful if something seems corrupted
6 History
CommandDescription
git logView the full commit history of your repository
git log --onelineCompact one-line view of commit history
git log --graph --all --decorateVisual branch graph showing all branches and tags
git log -pFull history including the actual diff changes in each commit
git log --author="name"Show only commits made by a specific author
git reflogShow all reference changes — best tool for recovering lost commits
git blame filenameShow who changed each line in a file and when
Undoing Changes
7 Reset (--soft keeps changes, --hard deletes them)
CommandDescription
git reset --soft HEAD~1Undo the last commit but keep all changes staged
git reset --hard HEAD~1Undo the last commit and permanently delete all changes
git reset --hard origin/mainReset your local branch to exactly match GitHub, removing local changes
git reset --hard <hash>Go back to a specific commit and remove all later changes permanently
git reset --hard ORIG_HEADUndo the last reset, restoring the repository to its previous state
Note: Reset only affects your local repository. Your GitHub copy is unchanged — you can always git pull to recover.
8 Restore, Revert & Clean
CommandDescription
git restore filenameRevert a file to its state in the last commit, discarding your changes
git restore --staged filenameRemove a file from the staging area without discarding your edits
git revert <hash>Create a new commit that undoes a previous one — keeps history visible
git checkout <hash> -- filenameRestore a specific file from a previous commit without changing anything else
git clean -fdDelete all untracked files and folders — cannot be undone
git cherry-pick <hash>Apply a specific commit from another branch onto your current branch
git rebase -i HEAD~nInteractively edit, squash, reorder, or drop your last n commits
Branching
9 Branches
CommandDescription
git branchList all local branches — current branch is marked with *
git switch -c new-branchCreate a new branch AND switch to it immediately
git checkout -b new-branchSame as above — older syntax for creating and switching in one step
git switch branch-nameSwitch to an existing branch
git branch -m old newRename a branch
git branch -d branch-nameDelete a branch safely — use -D to force delete unmerged branches
10 Merge & Rebase
CommandDescription
git merge branch-nameMerge another branch into your current one — creates a merge commit
git rebase branch-nameReplay your commits on top of another branch — cleaner history but riskier
11 Stash
CommandDescription
git stashSave current uncommitted changes and revert files to the last commit
git stash listShow all saved stashes with their index numbers
git stash popRestore the most recent stash and remove it from the list
git stash apply stash@{n}Restore a specific stash but keep it saved for reuse
git stash drop stash@{n}Delete a specific stash you no longer need
git stash clearDelete ALL stashes permanently
Remote & Tags
12 Remote Operations
CommandDescription
git remote -vShow all remotes and their URLs (fetch and push addresses)
git remote add origin <url>Connect your local repo to a GitHub URL for the first time
13 Tags & Versions
CommandDescription
git tagList all tags in your repository
git tag -a v1.0 -m "Version 1.0"Create an annotated tag with a message for a release
git push origin v1.0Upload a specific tag to GitHub
git push origin --tagsUpload all local tags to GitHub at once
Sparse Checkout (Advanced)
14 Partial Clone Setup (checkout only some files from a large repo)
CommandDescription
git clone --no-checkout <url>Clone the repo without checking out any files yet
git sparse-checkout init --no-coneEnable sparse-checkout using Git's pattern mode
git sparse-checkout set --no-cone '/*' '!/*/'Keep root-level files only, exclude all directories
git sparse-checkout listShow the patterns Git is currently checking out
15 Selecting Specific Files
CommandDescription
git ls-tree -r --name-only HEAD -- folderList every file inside a folder without checking any of them out
... | head -40 | git sparse-checkout add --stdinAdd just the first 40 listed files to the sparse checkout
... | sed -n '41,80p' | git sparse-checkout add --stdinAdd a later range (e.g. files 41–80) without starting over
git sparse-checkout add path/to/fileExplicitly add one exact file — safest way to guarantee it's included
Tip: Because ls-tree lists recursively, a wanted file might land inside a range by accident — add exact must-have files explicitly to be safe.
