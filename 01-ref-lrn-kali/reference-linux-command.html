Terminal Fundamentals
1 Terminal Basics
CommandDescription
whoamiPrint the name of the currently logged-in user
pwdPrint Working Directory — shows your current location in the file system
clearClear all output from the terminal screen (does not delete history)
historyDisplay a numbered list of previously run commands in this session
!NUMBERRe-run a specific command by its history number (e.g. !42)
exitClose the current terminal session or log out of a shell
2 Keyboard Shortcuts
ShortcutDescription
TabAutocomplete a command, file name, or path — press twice to see all options
↑ / ↓Cycle through previous and next commands in history
Ctrl + CForce-stop the currently running command or process
Ctrl + LClear the terminal screen (same as running clear)
Ctrl + DSend end-of-file signal — exits the current shell or Python/Node REPL
3 Getting Help
CommandDescription
command --helpShow a brief usage summary for almost any command (e.g. ls --help)
man lsOpen the full manual page for a command — scroll with arrow keys, press q to quit
which pythonShow the full file path of a command's executable (e.g. /usr/bin/python3)
command -v nmapCheck whether a command is installed; returns its path or nothing if missing
Files and Directories
4 Navigation
CommandDescription

cd folderEnter a named folder (e.g. cd Documents)

5 Create and Read Files and Folders
CommandDescription

touch f1 f2 f3Create multiple empty files at once in a single command
cat file.txtPrint the full contents of a file directly to the terminal
less file.txtRead a file one screen at a time — scroll with arrow keys, press q to quit

ShortcutActionNotes

7 Copy, Move, and Delete
CommandDescription
cp file.txt backup.txtCopy a file to a new name or location
cp -r folder1 folder2Recursively copy an entire directory and all its contents
mv file.txt folder/Move a file into a different directory
mv old.txt new.txtRename a file / folder — moving it to a new name in the same location
rm file.txtDelete a file permanently (no Trash/Recycle Bin)
rmdir folderDelete a directory — only works if the folder is completely empty
rm -r folderRecursively delete a directory and everything inside it
Working with Text
8 Echo and Redirection
CommandDescription
echo "Hello"Print text to the terminal output
echo "Hi" > file.txtWrite text to a file — overwrites existing content
echo "Hi" >> file.txtAppend text to the end of a file without erasing what's there
9 Grep and Pipe
CommandDescription
grep "word" file.txtSearch for a word or pattern inside a file; prints matching lines
grep "Hello" hello.txtFind all lines containing "Hello" in hello.txt
ls | grep ".txt"List files, then filter the output to show only .txt files
cat file.txt | grep "word"Read a file and filter lines to only those matching a word
command1 | command2Pipe — sends the output of command1 as the input to command2
10 Find and Locate
CommandDescription
find . -name "*.txt"Search recursively from the current directory for files matching a pattern
locate filenameQuickly find a file by name using a pre-built database index (faster than find)
sudo apt install plocate -yInstall the locate command if it's not already available
11 View File Content
CommandDescription
head file.txtShow the first 10 lines of a file (default)
head -n 20 file.txtShow the first N lines of a file
tail file.txtShow the last 10 lines of a file (default)
tail -n 20 file.txtShow the last N lines of a file
tail -f file.logWatch a file in real time — new lines appear as they are written (useful for logs). Press Ctrl+C to stop.

CommandDescription

15 Symbolic chmod
SymbolMeaning
uUser / Owner
gGroup
oOthers
aAll — owner, group, and others
+Add / give a permission
-Remove / take away a permission
rRead
wWrite
xExecute
CommandDescription
chmod u+rwx file.shGive the owner read, write, and execute permission
chmod u+rw file.txtGive the owner read and write permission
chmod u+x file.shMake the file executable by the owner
chmod g+rw file.txtGive the group read and write permission
chmod o+r file.txtGive all other users read permission
chmod a+rwx file.shGive everyone (owner, group, others) full permissions
chmod u-x file.shRemove execute permission from the owner
chmod g-w file.txtRemove write permission from the group
chmod o-r file.txtRemove read permission from others
chmod a-w file.txtRemove write permission from everyone

Ownership, Users and Groups
19 chown — File Ownership
CommandDescription
sudo chown username file.txtChange the owner of a file to a different user
sudo chown username:group file.txtChange both the owner and group of a file at once
sudo chown -R username folderRecursively change ownership of a directory and all its contents
sudo chown -R username:group folderRecursively change owner and group of a directory and all contents

CommandDescription

21 Groups

22 sudo and Root
CommandDescription

Software and Packages
23 APT Package Management
CommandDescription
sudo apt updateRefresh the local list of available packages from repositories — run this first before installing
sudo apt upgradeUpgrade all installed packages to their latest available versions
sudo apt full-upgrade -yUpgrade packages and also handle changes in dependencies (more thorough than upgrade)
sudo apt install package -yInstall a new package; -y automatically answers Yes to all prompts
sudo apt remove packageUninstall a package but keep its configuration files
sudo apt autoremoveRemove packages that were installed as dependencies but are no longer needed
24 Search and List Software
CommandDescription
apt search nmapSearch available packages by keyword — no sudo needed
apt list --installedShow all packages currently installed on the system
command -v nmapCheck if a specific command is installed (returns path or empty)
which nmapShow the full path to an installed command's executable
